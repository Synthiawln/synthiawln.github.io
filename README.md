# Dashboard Anggaran & Realisasi Anggaran Tahunan

Dashboard visualisasi data anggaran dan realisasi anggaran tahun 2024–2025, dibuat sebagai bahan analisis dan pendukung pengambilan keputusan internal.

**Instansi:** BPK Perwakilan DIY (Magang — Data Visualisasi / Data Analyst Support)
**Periode:** Oktober 2025 – Desember 2025
**Tools:** Microsoft Power BI, DAX, Power Query

> ⚠️ **Catatan Kerahasiaan Data**

## Tentang Project

Dashboard ini dibangun untuk membantu tim BPK Perwakilan DIY memantau **anggaran vs realisasi** secara tahunan, sehingga memudahkan proses analisis dan pengambilan keputusan tanpa harus membuka data mentah satu per satu.

### Yang saya kerjakan
- Mengumpulkan dan membersihkan data anggaran dari berbagai sumber (Power Query)
- Merancang model data dan relasi antar tabel
- Membuat measure DAX untuk menghitung persentase realisasi terhadap anggaran
- Merancang visualisasi perbandingan anggaran 2024 vs 2025
- Menyusun layout dashboard agar mudah dibaca oleh pihak non-teknis

### Fitur Dashboard
- Perbandingan anggaran vs realisasi per periode
- Tren realisasi anggaran tahun 2024 dan 2025
- Filter interaktif (slicer) untuk eksplorasi data
- Ringkasan indikator utama (KPI card)

### Insight & Pembelajaran
Melalui project ini saya belajar bagaimana menyusun dashboard yang tidak hanya informatif tapi juga mudah dipahami oleh stakeholder yang tidak familiar dengan data mentah, serta pentingnya menjaga kerahasiaan data instansi saat menyusun laporan maupun portofolio publik.
